# Architecture and extension points

This is a local, single-operator prototype. React calls a FastAPI service over `/api`; SQLite persists telemetry, incident response proposals, sandbox state and audit records. A locally trained Bernoulli naive Bayes model scores handcrafted telemetry features. There is no LLM service, credential requirement, remote containment, shell execution, malware execution or real network scanning.

## Detection

`backend/app/detection.py` owns feature extraction, training, prediction and evaluation. Training labels are read only during training; prediction extracts source-specific features from telemetry and never reads the label. Unicode normalization recognizes some invisible-character obfuscation. Natural language in logs remains data and cannot invoke an action or alter model instructions. Explanations cite observable features rather than claiming certainty about attacker intent or AI authorship.

`data/train.json`, `data/evaluation.json` and `data/replay.json` are intentionally readable fixtures, regenerated by `scripts/generate_data.py`. Reserved example domains and documentation IP ranges keep examples non-operational. The evaluation set shares templates with training; its metrics verify plumbing and known blind spots, not real-world generalization. Use `scripts/evaluate.py` to refresh `docs/evaluation-results.json`.

## Campaign reconstruction

The service joins related events using identity, host or IP within a bounded time window, then derives campaign severity from the observed categories and progression. Shared entities are heuristic links, not proof of causality. Shared infrastructure can over-correlate unrelated events; clean stolen sessions can evade the feature detector. Model probabilities are uncalibrated.

## Human approval boundary

Investigation creates proposals only. The decision endpoint validates an explicit approval flag and operator input before a transaction changes local sandbox state. Rejected or previously decided proposals cannot execute. Each action applies only to its stored target; request bodies cannot substitute a target or arbitrary command. A session token protects mutation endpoints from simple cross-origin requests. This is not multi-user authentication or tamper-proof audit storage; bind the service to loopback.

## Official challenge integration

The supplied challenge sheet refers to a documented sandbox API, labeled development data, hidden evaluation data, baseline detector and published campaign scoring definition. None of these artifacts or endpoints were attached. This implementation therefore does not claim official API compatibility, hidden-set results, baseline superiority or campaign scoring compliance.

Once the official documentation is available, replace the local sandbox execution adapter with the documented simulator client while preserving the approval transaction and audit trail. Confirm simulator-only endpoints, action schemas, authentication, idempotency behavior, error handling and response verification. Do not add a production containment adapter. Map supplied telemetry through a validated normalizer, retrain on the development split, and evaluate the untouched hidden split using the published scoring definition.

## Practical limits

No generative authorship detector, executable malware analysis, production identity provider, external telemetry collector, distributed ingestion, role-based access control or production deployment is included. The live feed polls SQLite-backed state while replay advances fixtures. The demo models defensive decisions and their verification, not actual packet filtering or account revocation.
